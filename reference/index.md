# Package index

## All functions

- [`align_to_north()`](https://ataeub.github.io/coi/reference/align_to_north.md)
  : Align point cloud to y axis
- [`as_pt_cld()`](https://ataeub.github.io/coi/reference/as_pt_cld.md) :
  Convert an object to a point cloud
- [`boxdim()`](https://ataeub.github.io/coi/reference/boxdim.md) :
  Compute the box dimension structural complexity index for a given
  point cloud.
- [`canopy_stats()`](https://ataeub.github.io/coi/reference/canopy_stats.md)
  : Compute canopy height statistics from a point cloud.
- [`cci()`](https://ataeub.github.io/coi/reference/cci.md) : Compute the
  crown complementarity index (CCI) for two raw single tree point
  clouds.
- [`clip_rect()`](https://ataeub.github.io/coi/reference/clip_rect.md) :
  Clip a point cloud to an axis-aligned rectangle
- [`clip_rect_mesh()`](https://ataeub.github.io/coi/reference/clip_rect_mesh.md)
  : Clip a mesh3d object to an axis-aligned rectangle
- [`clip_z()`](https://ataeub.github.io/coi/reference/clip_z.md) : Clip
  point cloud vertically
- [`cloud_to_mat()`](https://ataeub.github.io/coi/reference/cloud_to_mat.md)
  : Convert tabular data to a point cloud matrix
- [`coi()`](https://ataeub.github.io/coi/reference/coi.md) : Compute the
  crown overlap index (COI) for two raw single tree point clouds.
- [`compute_coi()`](https://ataeub.github.io/coi/reference/compute_coi.md)
  : Compute the crown overlap index (COI) for a vector with interaction
  distances.
- [`enl()`](https://ataeub.github.io/coi/reference/enl.md) : Compute the
  Effective Number of Layers (ENL) for a voxelized point cloud.
- [`extract_dtm()`](https://ataeub.github.io/coi/reference/extract_dtm.md)
  : Extract digital terrain model from point cloud
- [`extract_interaction()`](https://ataeub.github.io/coi/reference/extract_interaction.md)
  : Extract interaction distances between two point clouds.
- [`extract_slope()`](https://ataeub.github.io/coi/reference/extract_slope.md)
  : Extract terrain slope from a DTM mesh.
- [`gen_sphere()`](https://ataeub.github.io/coi/reference/gen_sphere.md)
  : Generate an artifical voxelized point cloud of a sphere.
- [`is_pt_cld()`](https://ataeub.github.io/coi/reference/is_pt_cld.md) :
  Check if an object is a pt_cld
- [`point_dist_filter()`](https://ataeub.github.io/coi/reference/point_dist_filter.md)
  : Filter points by nearest-neighbour distance
- [`pt_cld()`](https://ataeub.github.io/coi/reference/pt_cld.md) :
  Create a point cloud object
- [`save_to_laz()`](https://ataeub.github.io/coi/reference/save_to_laz.md)
  : Save cloud to a .laz file
- [`sor()`](https://ataeub.github.io/coi/reference/sor.md) : Statistical
  outlier removal
- [`voxelize()`](https://ataeub.github.io/coi/reference/voxelize.md) :
  Voxelize matrix-like point cloud objects.
- [`z_normalize()`](https://ataeub.github.io/coi/reference/z_normalize.md)
  : Normalize point cloud to digital terrain model
